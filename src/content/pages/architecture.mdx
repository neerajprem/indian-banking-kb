## How to read this section

Topics are grouped by how much background they assume. If you are new to banking systems, start with core banking system architecture, then payment system architecture. The advanced topics assume you know both.

Patterns described here are common across the industry. Where a page describes how a named organisation works, it cites a public source; everything else is labelled illustrative.
